# GEO 智能管理系统 —— 页面布局结构与展现形式一览表

本文件整理了系统所有页面的**布局结构**与**展现形式**，帮助开发人员快速明确每个页面的视觉排布。

---

## 1. 📊 GEO 诊断中心

### 1.1 曝光监测
* **布局结构**：**左右分栏结构 (L-R Split)**
* **展现形式**：
  * 左栏（35%）：**表单输入面板**（用于设置诊断品牌及关键词）。
  * 右栏（65%）：**卡片流列表 (Cards Stream)**（流式加载各大模型的诊断卡片）。
  * 浮动展现：**右侧抽屉 (Drawer)**（点击“查看快照”时，从右侧滑出显示对话原图）。

### 1.2 竞品分析
* **布局结构**：**对比分析仪表盘 (Comparative Dashboard)**
* **展现形式**：
  * 上部：**搜索与配置筛选栏**（选择模型平台、核心品牌与配置的竞品品牌）。
  * 中部：**声量份额饼图 (SoV Pie Chart) & 推荐排位对比柱状图**（Echarts 动态组件）。
  * 下部：**竞品提及明细对比表格 (Comparison Table)**（并排展示品牌与竞品在大模型回答中的推荐排名、原文提及上下文及情感态度评分）。

### 1.3 诊断快照
* **布局结构**：**上下结构 (T-B Grid)**
* **展现形式**：
  * 上部：**条件筛选栏 (Filter Bar)**（支持筛选时间、平台和提问词）。
  * 下部：**网格相册 (Image Grid)**（每行 4 张卡片的截图列表）。
  * 浮动展现：**全屏灯箱 (Lightbox)**（双击或点击查看原图大图）。

### 1.4 诊断历史
* **布局结构**：**上下结构 (T-B Table)**
* **展现形式**：
  * 上部：**搜索过滤栏**。
  * 下部：**数据表格列表 (Data Table)**（展示历史诊断任务，带分页）。

### 1.4 收录报表
* **布局结构**：**仪表盘网格结构 (Dashboard Grid)**
* **展现形式**：
  * 顶部：**数据指标卡片 (Metrics Cards)**（横向排列 4 个核心汇总数据卡）。
  * 下部：**可视化图表网格 (Echarts Grid)**（2*2 四宫格，折线图、柱状图、饼图混合展现）。

## 2. 🎯 核心词库

### 2.1 词库管理
* **布局结构**：**左树右表结构 (Tree-Table Split)**
* **展现形式**：
  * 左栏（20%）：**树状分类目录 (Tree Directory)**（展示词库的多级分类）。
  * 右栏（80%）：**多选数据表格 (Checkable Table)**（展示词汇详情，支持批量删除、移动分类等操作）。

### 2.2 热度指数
* **布局结构**：**上下结构 (T-B Split)**
* **展现形式**：
  * 上部：**居中大搜索框**（支持单行搜索与批量文本域换行输入）。
  * 下部：**图表+列表对照**（左侧为多维度热度趋势图，右侧为相关衍生词列表）。

### 2.3 AI 智能拓词
* **布局结构**：**左右分栏结构 (L-R Split)**
* **展现形式**：
  * 左栏（35%）：**表单输入面板**（设置种子词和拓展规则）。
  * 右栏（65%）：**多选结果列表 (Checkable List)**（AI 实时拓词输出，带打字机输出动效，支持勾选一键存入词库）。

### 2.4 规则拓词
* **布局结构**：**多列并排表单 + 下方数据表格**
* **展现形式**：
  * 上部：**三列并排文本框 (Three-column Textareas)**（前缀词、核心词、后缀词输入栏）。
  * 下部：**拼装结果列表 (Table View)**（展示自动组合出的词汇矩阵）。

## 3. 🧠 品牌配置

### 3.1 事实库
* **布局结构**：**左树右表/表单结构 (Tree-Form Split)**
* **展现形式**：
  * 左栏（25%）：**文档分类树**。
  * 右栏（75%）：**折叠面板列表 (Collapse/Accordion)**（折叠展示 Q&A 或段落内容，点击展开或直接在行内编辑）。

### 3.2 官网同步
* **布局结构**：**网格配置卡片 + 右侧侧边抽屉 (Cards + Drawer)**
* **展现形式**：
  * 左侧（网格）：**同步任务卡片**（展示配置的官网 URL、同步周期及最近一次同步的网页数量、成功率与时间）。
  * 右侧（抽屉）：**任务同步日志看板**（点击卡片日志时滑出，展示每次爬取的子网页 URL 详情、切片生成数量及异常报警信息）。

### 3.3 媒体资产
* **布局结构**：**网格相册 + 右侧抽屉结构 (Grid + Drawer)**
* **展现形式**：
  * 左侧大网格：**卡片网格 (Card Grid)**（展示品牌图片及绑定的 ALT 标签）。
  * 浮动展现：**右侧抽屉面板 (Drawer)**（点击图片卡片时，右侧划出进行标签修改与删除配置）。

## 4. 🎨 内容工作坊

### 4.1 标题生成
* **布局结构**：**左右分栏结构 (L-R Split)**
* **展现形式**：
  * 左栏（35%）：**表单配置区**（输入主旨和核心要求）。
  * 右栏（65%）：**标题卡片列表 (Cards List)**（展示生成出来的标题，点击直接复制或一键采用写文）。

### 4.2 Prompt 模板
* **布局结构**：**上下结构 (T-B Grid)**
* **展现形式**：
  * 上部：**筛选及分类 Tab**。
  * 下部：**卡片式网格 (App Store Cards)**（卡片展示 Prompt 模板，支持新建、复制和调试模版）。

### 4.3 分类管理
* **布局结构**：**单栏树状管理结构 (Tree CRUD)**
* **展现形式**：**多级树状图列表 (Tree View)**（支持直接在树节点上操作增删改）。

### 4.4 批量写作
* **布局结构**：**步骤向导 + 下方卡片列表 (Wizard + Cards)**
* **展现形式**：
  * 上部：**步骤进度条 (Steps)**（展示当前第几步配置）。
  * 下部：**任务进度卡片列表**（以列表项形式展示进行中和历史的批量生成任务，带流动进度条）。

### 4.5 稿件管理
* **布局结构**：**左树中表结构 (Tree + Table)**
* **展现形式**：
  * 左栏（20%）：**多级分类树**。
  * 右栏（80%）：**数据表格 (Data Table)**（包含批量导出、批量分发等操作）。

### 4.6 稿件精修（编辑器）
* **布局结构**：**三栏式工作区结构 (Three-Column Workspace)**
* **展现形式**：
  * 左侧（15%）：**分类文件目录树**。
  * 中间（55%）：**富文本/Markdown 编辑区**。
  * 右侧（30%）：**GEO 得分仪表盘及事实核对折叠栏**（用于评估文章并一键修正幻觉）。

### 4.7 宣发日历
* **布局结构**：**全屏日历看板布局 (Full-width Calendar Workspace)**
* **展现形式**：
  * 主显示区：**月度/周度内容网格日历 (Grid Calendar)**（将定时发布或已发布的稿件作为便签卡片呈现在对应日期格子中，以不同颜色区分状态：待发送、已发送、发送失败）。
  * 交互逻辑：**卡片拖拽 (Drag & Drop)**（直接拖放卡片改变发布时间；双击格子可弹窗直接创建新写作或分发排期）。

### 4.8 流量裂变舱
* **布局结构**：**两栏编辑器对照 + 右侧侧栏结构 (Dual Editor + Sidebar)**
* **展现形式**：
  * 左侧（25%）：**外部 URL 抓取解析原文区**（展示爬取来的爆文大纲、关键词）。
  * 中间（45%）：**AI 生成复刻稿件区**（富文本编辑器）。
  * 右侧（30%）：**GEO 优化评估侧边栏**。

---

## 5. 🚀 宣发矩阵

### 5.1 全渠道宣发控制台
* **布局结构**：**Tab 标签页切换 + 底部数据表格 (Tabs + Table)**
* **展现形式**：
  * 顶部：**水平 Tab 页切换栏**（独立站、自媒体、B2B、媒体/大V）。
  * 中部：**卡片网格**（根据切换的 Tab，分别展示绑定的独立站站点、自媒体账号或商贸 API 配置卡片）。
  * 底部：**通用分发监控表格 (Global Sync Table)**（汇总展示所有文章的分发记录及大模型收录状态，带呼吸状态灯）。

---

## 6. 👤 账户中心

### 6.1 个人中心/控制台
* **布局结构**：**Tab 标签页切换结构 (Tabs Layout)**
* **展现形式**：
  * **Tab 1: 身份核验** ➔ **双栏表单**（左侧填写资质，右侧上传证件照片）。
  * **Tab 2: 套餐权益** ➔ **仪表盘网格**（环形百分比展示每日诊断、并发数、分发次数等日配额）。
  * **Tab 3: 算力变动明细** ➔ **多标签子表格**（切换查看“点数变动流水”与“现金交易流水”）。
